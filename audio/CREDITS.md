# Источник озвучки

Русский синтетический женский голос «Ксения», выбранный владельцем после прослушивания образца 13.09.2026.

- Автор модели: Silero Team.
- Проект: https://github.com/snakers4/silero-models
- Модель: `v5_5_ru`, голос: `xenia`, 48 000 Гц, моно, PCM 16 бит.
- Модель получена с официального адреса: https://models.silero.ai/models/tts/ru/v5_5_ru.pt
- Лицензия модели: [CC BY-NC-SA 4.0](https://github.com/snakers4/silero-models/blob/master/LICENSE). Модель не включена в приложение; синтез выполнен локально для открытого учебного проекта.
- В аудиофайл объединены пять фрагментов текста приложения с паузами 0,55 секунды. Текст находится в `transcript-ru.txt`; границы этапов — в `narration-cues.js`.

В браузере воспроизводится готовая запись. Системный синтез речи и внешние API не используются.
