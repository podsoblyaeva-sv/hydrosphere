# Гидросфера

Интерактивное приложение для изучения водной оболочки Земли: состав гидросферы, круговорот воды, 3D-модель, факты и тест из 10 вопросов.

## Открыть приложение

https://podsoblyaeva-sv.github.io/hydrosphere/

Приложение открывается без регистрации в Claude. Для самостоятельного запуска скачайте репозиторий и откройте `index.html` в современном браузере с поддержкой WebGL.

## Содержимое

- `index.html` — разметка, оформление и код приложения.
- `responsive_v2.css` — адаптация для телефонов: без обрезания по ширине, с прокруткой вниз.
- `vendor/three.min.js` — Three.js r128 для отображения 3D-модели.
- `vendor/LICENSE-three.txt` — лицензия Three.js.

Изображения встроены в HTML; библиотека Three.js хранится в репозитории. Шрифты загружаются из Google Fonts, при недоступности используются системные шрифты.

## Подготовка к публикации — 12.09.2026

Перенесено из предоставленного владельцем артефакта Claude. Добавлены UTF-8, русский язык документа и настройка экрана для мобильных устройств. Исправлен запуск анимации при первом открытии вкладки 3D. Учебное содержание сохранено из исходника.

Все пять разделов проверены на пяти размерах окна от 320 до 844 пикселей, включая горизонтальную ориентацию телефона. Карточки увеличиваются под текст, кнопка звука находится вверху, а нижняя навигация учитывает безопасные отступы устройства.
